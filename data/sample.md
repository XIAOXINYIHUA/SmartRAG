# SmartRAG 示例文档

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将检索与生成结合的技术。

### 核心流程

1. **索引阶段**：将文档切片、向量化、存入向量数据库
2. **检索阶段**：用户提问时，将问题向量化，在库中找到最相关的片段
3. **生成阶段**：将检索结果作为上下文，交给 LLM 生成最终回答

### 优势

- 减少幻觉：回答基于真实文档，而非纯靠模型记忆
- 可溯源：每条回答可以追溯到原始文档来源
- 知识更新快：换文档即可更新知识库，无需重新训练模型

## 技术栈

SmartRAG 使用以下技术：

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 框架 | LangChain | Agent 和链的编排 |
| 向量库 | ChromaDB | 轻量级本地向量数据库 |
| 嵌入 | OpenAI text-embedding-3-small | 文本向量化 |
| LLM | GPT-4o-mini | 问答生成 |
| UI | Streamlit | Web 界面 |
